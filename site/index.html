8 步闭环

        

          
1 设计系统改动Figma Variables 改按钮颜色、字号、内间距。

          
2 发布 Figma LibraryOwner 发布库版本，说明影响范围。

          
3 导出 token JSON插件读取变量、模式和 code syntax。

          
4 转换三端代码本 demo 转网页 CSS，也生成 Swift/Kotlin/ArkTS 样例。

          
5 CI 自动验收校验 token、对比度、缺失字段。

          
6 发布 Design KitGitHub Pages 发布预览；客户端场景可发布 SDK 包。

          
7 客户端升级依赖业务页面只升级 Design Kit 版本。

          
8 灰度与回滚从 history 选择旧 JSON 恢复 current。
